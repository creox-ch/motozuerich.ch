## Метод / оговорка

Все находки сверены с **живым продом через браузер с выполнением JS** (и симуляцией cookie-согласия), не только
`curl`/сырой HTML. Урок сессии: **`curl` и Playwright с `networkidle` не видят consent-gated трекинг** — вывод
«чего-то нет» из грубого инструмента дважды оказался ложным (GA, потом Meta-Pixel). Проверять теги — только
в браузере с согласием. Полный лог прогона: `test-results/` + сохранённый вывод сессии.
